# Already rejected

Looks, patterns and ways of working Nadav has rejected. Read before proposing anything visual.
Nothing here is proposed again; if a project seems to need one of them, that is a question for
him, with this entry quoted.

Each project keeps its own `REJECTED.md` at its root (the skill appends to it whenever he rejects
something, with his words and the date). This file is the starting list a new project's file is
seeded from: the **general** entries always, the **project** entries only as examples of his
taste, since each was said about one product.

How to read the quotes. Hebrew in quotation marks is what he typed, typos included, taken from
the session transcript of that date; the source column names the memory file or decision that
records the event. *(summary)* marks a record written by an agent in its own words, where his
exact words were not kept. A decision number refers to
`~/design-redesign/therapy-flow-v2/DECISIONS-ANSWERED.md`.

## Agent defaults that match his rejections (not his words)

Written by agents in MediZen's BRIEF and in this skill's rules; he approved those documents as
a whole and never ruled on these lines one by one. Treat them as defaults.

- The generic AI look: gradient text, glass, purple, icon-in-circle grids, walls of hero metrics.
- Impeccable `craft`, `bolder`, `overdrive` and `delight` on an existing product (the skill's hard
  rule; `rules/working-style.md` names the first three).
- A second action colour; the alarm colour on a count, a category or a zero; colour as the only
  carrier of a status.
- A disabled control without its reason; a placeholder as a label; a tooltip as the only
  explanation; an error that dismisses itself.
- Icon-only navigation; a hamburger on a desktop; more than five items in a phone's bottom bar.

## A reviewer's opinion is not his

A critic recommended the serif display face in four places; he removed it everywhere (#328). A
reviewer's recommendation on taste is a proposal to show him, never a finding to apply.
