# ux-next

This is a shortcut for the `next` mode of the **nadavai:nadav-design** skill. Same plugin, same version, always.

1. Invoke the Skill tool with skill `nadavai:nadav-design` and args `next $ARGUMENTS` (the mode word first, then whatever Nadav typed). If the Skill tool cannot load it, read `${CLAUDE_PLUGIN_ROOT}/skills/nadav-design/SKILL.md` and follow its **Hard rules** and its first paragraph under the title (the `next` case) verbatim with `next $ARGUMENTS` as `$ARGUMENTS`. Never look for the master anywhere else.
2. Follow that paragraph, Hebrew chat. Starts nothing, prints the position and the next commands.
