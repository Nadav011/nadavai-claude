# Global npm packages this environment expects. One name per line, comments allowed.
# After a "|" comes the package's check: one command that must exit 0 when the tool works.
# `./update.sh --npm` runs it before and after updating and names a package whose check stopped
# passing. Only this command runs, so name one that starts nothing (memlab has none: its
# version command hangs).
# Installed by `./setup.sh --npm` or `./update.sh --npm`, never automatically:
# it is a few hundred MB and a new machine rarely needs all of it on day one.
#
# fnm keeps global packages PER NODE VERSION. Install them under the version
# `fnm default` points at, or a new shell will find none of them.
