# Model routing (set 2026-10-11)

Aliases `haiku`, `sonnet`, `opus` resolve to claude-haiku-5-5, claude-sonnet-5-5, claude-opus-5-5.

- Fable is never used: not as the main loop, not as a subagent, not as a fallback when Opus is stuck. Why: Nadav ruled it out on 2026-10-13, after finding that settings.base.json had made it the default model for fresh installs. Enforced by `availableModels: ["opus", "sonnet", "haiku"]` in settings.base.json: a request for Fable (main loop, subagent or teammate) falls back to an allowed model instead, because a team lead whose session predated this rule still spawned a Fable teammate on 2026-10-12.
- Main loop: Sonnet 5.5 at xhigh, set by `/model` (global) and by `model` in settings.base.json. Move to Opus 5.5 for architecture, hard debugging and security work. Why: Opus burns the 5-hour quota several times faster.
- Subagents: leave `model` unset so they run on Sonnet 5.5 (`CLAUDE_CODE_SUBAGENT_MODEL`). Pass `haiku` for search, lookups and doc edits (explore, writer). Pass `opus` for planner, architect, critic, debugger, verifier, security-reviewer and code-reviewer. Why: a hard bug or a completion gate costs more when the model is weaker than it costs in quota; the volume is in executors and forks.
- Executors (and the implement/fix agents in a Workflow script): `opus` for complex or multi-file work, and always when the change touches money or payments, auth, permissions or RLS, migrations, deletion or data loss, or messages and sends to real people (judged by the files and actions involved, not by the task title), and for every fix round after a rejected review or a red CI. Sonnet only for small, contained work: one or two files, none of those areas; its brief says to stop and return if the change reaches one of them. Reviewers stay on Opus, and the nadav-design skill's own agents keep the models it names. Why: measured on 2026-11-04 with `executor-quality` (clear verdicts, distinct reviews, all transcripts), reviews rejected 7 of 10 Sonnet executor batches against 25 of 52 Opus ones, and 6 of 7 against 24 of 46 on runs over 60 tool calls. A Sonnet default was tried that day and rolled back on these numbers, because Nadav's condition was no loss of quality. Before trying it again, re-measure with `executor-quality --since 2026-11-04` on at least 30 clear Sonnet reviews; it does not cover Workflow agents yet.
- Code lookup: definitions, types and a file's symbols through LSP (the `LSP` tool or OMC `lsp_*`: `goToDefinition`, `hover`, `documentSymbol`) before grep or reading whole files; grep for free text. Why: in the week to 2026-11-03, Bash search and cat/sed reads were 94% of Bash output (~450M chars), and every result is re-read by each later request in that context.
- Before a rename, a delete or a signature change, find every use with `rg -w --hidden -g '!.git' <name>` (scoped to the repo, `-l` first when the list is long; `--hidden` reaches `.woodpecker/`, `.github/` and `.claude/`), never with LSP `findReferences` or `incomingCalls` alone. Why: tsserver searches only the tsconfig projects it has loaded; on therapy-flow-v2 (2026-11-04) it returned 1 of 8 uses on the first call and 3 on the second, missed the test files (a separate `tsconfig.tests.json`), and no tsconfig there covers the 694 Deno files in `supabase/functions`.
- A subagent's brief carries the paths, the findings so far and the question, so it does not re-explore what the caller already read. A subagent never blocks over ~5 minutes inside itself (`ci-wait`, `heavy-slot`, `ssh`, a long suite): it returns what it did and the exact wait command, and the caller runs the wait in the background. Why: a subagent's prompt cache lives 5 minutes, and waits past that rewrote ~280K tokens each time, ~32% of cache-write cost that week. Switching subagents to a 1 h cache (`CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL`) was measured as break-even, because every 1 h write costs 2x instead of 1.25x.
- `token-audit [days]` measures where tokens go (by model, agent type, tool, cache-write cause). Run it before and after any change meant to save tokens.
- No forks for routine delegation. A fork inherits the parent model and its full context (median ~290K tokens per request). Why: on 2026-10-06, 97% of subagent requests ran on Opus and froze the session limit.
- Effort: xhigh for Opus and Sonnet, never global max (it scores lower than xhigh on Sonnet 5.5's own benchmarks).
- A new model ships: update `CLAUDE_CODE_SUBAGENT_MODEL` and `modelSettings` in settings.base.json, and the tiers in `~/.config/claude-omc/config.jsonc` (outside this repo).
