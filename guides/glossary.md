# Nadav's glossary (all projects)

Words Nadav uses whose meaning holds in every project. An agent reads this file, and the
project's own `GLOSSARY.md`, before asking what a word means (`rules/working-style.md`,
"Requests": the understanding check). A project's `GLOSSARY.md` wins over this file for that
project. An entry is added here only after Nadav approves it as cross-project.

Format, one entry per term:

- **<his word>**: what it means, in one or two sentences. Example he chose: <the concrete
  example>. Source: <project>, <date>.
